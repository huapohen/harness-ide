# 右侧目录树回归检查（2026-09-13）

范围：右侧 File、目录树空白处菜单、新建/粘贴/重命名/删除、标签归属、自动保存及会话恢复。

## 修复

- 左右打开同一路径的外部文件使用不同标签标识和打开请求去重键；另存为、重命名、拆分及会话恢复保留标签归属。已有未保存的同路径文本会复制当前编辑状态，避免新视图退回磁盘旧内容。
- 根目录切换或关闭使旧操作失效；新建/粘贴确认后和异步关闭标签后重新校验，防止操作错误的根目录。没有右侧根目录时不再隐式回退到左侧目录。
- 多选后键盘删除处理全部选中项，父子重复只处理父目录；方向键移动同步选择状态。
- 新建和粘贴展开所有祖先目录；剪切移动更新展开路径并保存选中状态。
- 终端启动使用返回的终端实例，避免等待启动时选中其他标签后发错命令；终端关闭或视图卸载后停止延迟发送。

## 验证

- 128 项自动化测试通过，新增异步上下文作废、父子多选去重、祖先展开、左右打开请求隔离及自动保存隔离测试。
- 实际窗口验证右侧独立文件标签、Save/Save As 可用、完整 File 菜单及根目录右键菜单。
- Plugins 显示 Up to date。

## 当前限制

右侧目录树是本地文件系统；左侧连接 SSH 时，右侧本地目录的集成终端暂不可用并显示明确提示，避免把本地路径发送给远程 shell。未对用户文件执行破坏性验证。

# A little space to build.

一个轻量的工作台。文件、终端和你的工具，各就其位。

> **Everything is a plugin.** 让核心保持简单，让能力自由组合。

## 一个标签栏，所有上下文

终端和文档共享标签栏。打开文件，切回 Shell，再开一个终端——不用在两套导航之间来回寻找。

| 标签 | 内容 | 引擎 |
| --- | --- | --- |
| `Terminal 1` | 交互式 Shell | Shell + PTY |
| `welcome.md` | 当前文档 | Markdown |
| `Terminal 2` | 独立会话 | Shell + PTY |
| `notes.md` | 工作笔记 | Markdown |

点击右上角 **⊟**，把终端放在文档下方；再次点击，收回同一标签栏。拖动标签可以调整顺序。

## 只带上需要的工具

- **Explorer** — 浏览工作区，编辑和保存文本
- **Documents** — Markdown、PDF、HTML 预览
- **Git** — 差异、暂存与提交
- **Remote** — SSH 远程文件与终端
- **Themes** — One Dark Pro / Light

---

`⌘ T` 新终端　 `⌘ S` 保存　 `⌘ K` 命令面板　 `⌘ B` 侧栏
